# GMM-STFT-VAEGAN

Implementation of a spectrum-conditioned STFT-VAEGAN with a response-spectrum consistency network (RSCN) for stochastic ground-motion time-history generation.

The code implements the VAEGAN training framework and the RSCN-based spectrum-consistency loss described in the associated paper.

## Reference

Hu, X., Chen, S., Ding, Y. et al. Generative AI for spectrum-compatible ground motion time history simulation. *Bulletin of Earthquake Engineering* (2026).

[https://doi.org/10.1007/s10518-026-02699-z](https://doi.org/10.1007/s10518-026-02699-z)
